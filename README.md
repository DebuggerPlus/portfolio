# DebuggerPlus Portfolio

A responsive, static developer portfolio website for GitHub Pages.

## Stack

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages

## Local preview

Open `index.html` in a browser. No build process or dependencies are required.

For a local HTTP server, from the project root:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

1. Push the repository to GitHub.
2. Open repository Settings → Pages.
3. Set source to `Deploy from a branch`.
4. Select branch `main` and folder `/ (root)`.
5. Save and wait for deployment.

For a user site, the repository should be named `USERNAME.github.io`.

## Customization

Update project links, descriptions, contact links and technology tags in `index.html`.
Project preview artwork is currently CSS-based placeholder artwork. Replace it with screenshots in `assets/images/` when available.
